# User Guide: Auditor

**Blueprint Progress Tracking Web Interface**

## Who this is for

`ViewAuditLog` only — read-only visibility into the audit trail, with no editing rights anywhere in the app.

## Signing in

Use whichever identity provider your organization has configured.

## The Audit Log Viewer

**Where**: **Admin > Audit Log Viewer**.

Read-only — no add/edit/delete. Filter by Event Type, Entity, and a From/To date range, then click **Filter**. The list shows Occurred At, Event Type, By, Entity, and Detail. Click **Occurred At** on any row to expand the recorded Reason (if any) and a Field / Old Value / New Value table.

## The Dashboard

**Where**: `Dashboard` in the top nav — also reachable from this role.

Four summary cards: Accounts by Stage, Key Progress Indicators, Overdue/At-Risk Accounts, and Risk Exceptions Needing Attention (general overdue-review count only). See `User_Guide.md`'s Dashboard section for details.

## Your profile

**Where**: the user menu (`/profile`). Shows your display name, role, and permission list, and lets you pick a display theme.
